# CLAUDE.md

This project's agent instructions are maintained in a single, agent-neutral file so they
work the same for Claude Code and Codex.

**→ Read [AGENTS.md](AGENTS.md) and follow it.**

Quick pointers:
- New clone? Run the **setup-profile** skill first to replace the sample persona with the
  user's real data.
- Workflow playbooks live in `.claude/skills/<name>/SKILL.md` (Claude auto-loads these as
  skills). The equivalents for Codex are in `.codex/prompts/`.
- Career data is the single source of truth in `data/*.yaml`; CVs are generated by
  `scripts/build_cv.py`. Never hard-code data into generated CVs, and never fabricate facts.
